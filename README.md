## 📖 About The Project

**Grama-Vaxi** is a purpose-built Android application designed specifically to assist with rural livestock vaccination and healthcare management. Recognizing the challenges faced by rural communities and veterinarians, this application prioritizes an accessible, intuitive, and efficient user interface. 

The core philosophy behind Grama-Vaxi is to bridge the digital divide by offering a robust tool that operates seamlessly on low-end devices while maintaining a modern, clean aesthetic.

### ✨ Key Design Philosophies
- **Accessibility First**: Designed with large buttons, high-contrast text, and straightforward navigation to ensure usability for individuals with varying levels of technological proficiency.
- **Low-End Device Support**: Optimized layouts and resource management ensure smooth performance even on budget or older Android smartphones commonly used in rural areas.
- **Clean Healthcare UI**: A modern, trustworthy, and organized interface that brings enterprise-level design to rural agricultural applications.

---

## 🚀 Features

The application features a complete UI flow for managing livestock health records and vaccination schedules:

- **🔐 Secure Access**: Simple and straightforward login interface.
- **📊 Interactive Dashboard**: A centralized hub providing quick access to all essential features.
- **📝 Animal Registration**: Easy-to-use forms for registering new livestock into the system.
- **🏥 Health Records Management**: View and track vaccination history and medical records for individual animals.
- **📘 Health Guide**: Access to vital information and best practices for livestock care.
- **👤 User Profiles**: Manage user settings and application preferences.

---

## 📱 Application Screens & Navigation Flow

1. **Welcome Screen (`MainActivity`)**: An inviting onboarding experience.
2. **Login (`LoginActivity`)**: Authentication portal.
3. **Dashboard (`DashboardActivity`)**: The main menu displaying quick action cards.
4. **Register Animal (`RegisterAnimalActivity`)**: Data entry screen for livestock.
5. **Health Records (`HealthRecordsActivity`)**: History and tracking interface.
6. **Health Guide (`HealthGuideActivity`)**: Educational resources.
7. **Profile (`ProfileActivity`)**: Account management.

## 💻 Getting Started

### Prerequisites
- Android Studio (Latest Version recommended)
- Minimum SDK: API 24 (Android 7.0) or lower depending on exact Gradle config
- Kotlin Plugin installed in Android Studio

### Installation & Run Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/CodeBellator/Grama-Vaxi.git
   ```
2. **Open the project:**
   Launch Android Studio, select `Open an existing Android Studio project`, and navigate to the cloned directory.
3. **Sync Gradle:**
   Allow Android Studio to sync the project and download all necessary Gradle dependencies.
4. **Run the App:**
   Connect a physical Android device or start an Android Emulator. Click the `Run` ▶️ button in Android Studio.
